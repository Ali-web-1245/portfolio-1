# 👤 Personal Portfolio Website (Portfolio-1)

Welcome to the repository of my first professional personal portfolio website. This project is a clean, minimal, and fully responsive frontend website built from scratch to showcase my skills, projects, and contact information as a web developer.

---

## ✨ Features
* **About Me Section:** A dedicated space highlighting my background, passion for development, and career goals.
* **Skills Showcase:** A visually clean grid displaying my technical expertise (HTML, CSS, JavaScript, etc.).
* **Projects Gallery:** A curated display of my frontend web applications with links to their repositories.
* **Contact Form/Links:** Easy access to my professional networks like GitHub, LinkedIn, and Email.
* **Fully Responsive Design:** Optimized for a seamless viewing experience across mobile phones, tablets, and desktops.

---

## 🛠️ Tech Stack & Implementation

The website is crafted entirely using pure frontend technologies, focusing on clean code architecture:

### 🌐 HTML5 (Structure)
* Built using semantic layout tags (`<header>`, `<nav>`, `<section>`, `<footer>`) to improve SEO and screen-reader accessibility.
* Organized with logical class naming conventions for seamless styling integration.

### 🎨 CSS3 (Design & Layout)
* Utilizes **Flexbox** and **CSS Grid** to achieve precise alignments, perfect spacing, and structural symmetry.
* Features a modern color palette, premium typography, custom card shadows, and smooth hover effects on buttons and links.
* **Mobile-First Approach:** Engineered with CSS Media Queries to ensure fluid adaptability on viewports of all sizes (Zero horizontal scrolling issues).

---

## 📁 Repository Structure

To ensure the project stays clean and maintainable, the files are structured as follows:
* `index.html` — The main entry point of the website (Root directory).
* `style.css` — The complete stylesheet containing layout grids and design tokens.
* `assets/` — (Optional) Folder containing profile pictures, project screenshots, and icons.
